# 📝 Multi-Step Form

An interactive multi-step form that guides users through a subscription process with a clear and user-friendly interface.

![Multi-Step Form Screenshot](./Multi-Step.png)

## 🚀 Live Demo

[View the Live Demo](https://omarabdelkhaliq.github.io/Multi-step-form/)

## ✨ Features

- Multi-step form navigation.
- Form validation.
- Subscription plan selection.
- Optional add-ons selection.
- Dynamic order summary.
- Confirmation screen after completing the form.
- Responsive user interface.

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript

## 📚 What I Learned

- Managing form state with JavaScript.
- Validating user input.
- Updating the DOM dynamically.
- Handling user interactions across multiple steps.
- Organizing interactive UI components.
